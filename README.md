# SPL_IT² app downloads

This repository holds only the Android app files (APK) for SPL_IT², a private expense-splitting app for a small group of friends. The app's code is not here.

**Install:** open the [latest release](https://github.com/Aslam7714/spl-it2-releases/releases/latest) on your Android phone, download the `.apk` file and open it. The first time, Android asks you to allow installs from your browser or files app.

**Update:** the app tells you when a new version is ready and installs it for you (Me > Update). Your data stays.

The app is signed with one private key; Android only installs an update over the app if it carries the same signature.
